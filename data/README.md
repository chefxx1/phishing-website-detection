# Dataset

**Phishing Websites** (file: `Training Dataset.arff`)

* 11,055 websites, 30 features, target column `Result` (-1 = phishing, 1 = legitimate)
* Source: UCI Machine Learning Repository, https://archive.ics.uci.edu/dataset/327/phishing+websites
* Creators: R. Mohammad, L. McCluskey (and F. Thabtah). DOI: https://doi.org/10.24432/C51W2X
* License: CC BY 4.0

Related paper: Mohammad, Thabtah and McCluskey (2014), "Predicting phishing websites based on self-structuring neural network", Neural Computing and Applications 25: 443-458.
